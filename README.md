# Present.me — 'Моя карта'

Страница на React по макету `prototype/frame-33.svg`: шапка, боковое меню, поиск, четыре карточки опыта и футер. 
Шрифт — TT Travels Next Trial Medium.

## Назначение и работа

Поиск помогает найти нужный проект, навык или запись об образовании для подготовки резюме или портфолио.

1. При открытии видны все карточки.
2. Ввод текста сразу отбирает записи по заголовку и описанию.
3. Например, `Figma` показывает один проект, а `интерфейсов` — две записи.
4. При отсутствии совпадений появляется «Ничего не найдено».
5. Крестик или кнопка «Показать всю карту» очищает запрос.

Регистр, пробелы по краям и различие между «е» и «ё» не влияют на поиск. Для нескольких слов запись должна содержать каждое из них.

## Запуск

Нужен Node.js 18.12 или новее.

```bash
npm install
npm start
```

Откройте `http://localhost:3000`.

Для Live Server используйте `/docs/index.html`. Корневой `index.html` перенаправляет на эту сборку. Файл `src/index.html` — шаблон Webpack, напрямую открывать его не нужно.

## Сборка и публикация

```bash
npm run build
```

Webpack создаёт папку `docs` с единственной страницей `index.html`. Скрипт, шрифт и изображения включены в сборку, пути относительные.

Для GitHub Pages загрузите проект вместе с `docs` в репозиторий. В **Settings → Pages → Deploy from a branch** выберите ветку с проектом и папку `/docs`.
