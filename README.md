# Present.me — моя карта

Единственная страница на React по макету `prototype/frame-33.svg`: шапка, боковое меню, поиск, четыре карточки опыта и футер. Шрифт — TT Travels Next Trial Medium, вес 500. Есть раскладка для узких экранов, hover-эффектов нет.

## Назначение и работа

Поиск помогает найти нужный проект, навык или запись об образовании для подготовки резюме или портфолио.

1. При открытии видны все четыре карточки.
2. Ввод текста сразу отбирает записи по заголовку и описанию.
3. Например, `Figma` показывает один проект, а `интерфейсов` — две записи.
4. При отсутствии совпадений появляется «Ничего не найдено».
5. Крестик или кнопка «Показать всю карту» очищает запрос.

Регистр, пробелы по краям и различие между «е» и «ё» не влияют на поиск. Для нескольких слов запись должна содержать каждое из них. Данные демонстрационные, сервер не используется.

Пункты меню и значки сохранены как элементы макета, переходы на другие экраны отключены. Контакты и адреса соцсетей не предоставлены.

## Запуск

Нужен Node.js 18.12 или новее.

```bash
npm install
npm start
```

Откройте `http://localhost:3000`.

Для Live Server используйте `/docs/index.html`. Корневой `index.html` перенаправляет на эту сборку. Файл `src/index.html` — шаблон Webpack, напрямую открывать его не нужно.

## Сборка и публикация

```bash
npm run build
```

Webpack создаёт папку `docs` с единственной страницей `index.html`. Скрипт, шрифт и изображения включены в сборку, пути относительные.

Для GitHub Pages загрузите проект вместе с `docs` в репозиторий. В **Settings → Pages → Deploy from a branch** выберите ветку с проектом и папку `/docs`.

Публикация пока не выполнена. После неё нужно добавить ссылки на работающую страницу, репозиторий и интерактивный прототип Figma.

Экспорт макета сохранён в `prototype/frame-33.svg`. Он не заменяет интерактивный прототип. Состояния и переходы описаны в `prototype/README.md`.

## Что в файлах

- `src/App.jsx` — вся страница.
- `src/components/Header.jsx` — шапка.
- `src/components/Menu.jsx` — меню слева.
- `src/components/Footer.jsx` — нижняя часть страницы.
- `src/components/Search.jsx` — поиск.
- `src/components/Card.jsx` — одна карточка.
- `src/components/Button.jsx` — кнопка.
- `src/data/cards.mjs` — тексты карточек.
- `src/style.css` — внешний вид.
- `img` — иконки и картинки.
- `webpack.config.js` — настройки сборки.

В поиске `text` хранит введённый текст, а `setText` меняет его. `cards` — все карточки, `foundCards` — найденные. `clearSearch` очищает поле.

`changeText` получает текст из поля. `stopSubmit` не даёт странице перезагрузиться при нажатии Enter.

Цикл `for` проверяет каждое слово: если его нет в карточке, она не показывается.

Поиск делает буквы маленькими, убирает лишние пробелы и проверяет, есть ли введённые слова в карточках. Затем React показывает подходящие карточки. Если поле пустое, видны все карточки.

## Проверка

Выполнена сборка Webpack. Через JSDOM проверены начальная выдача, поиск, отсутствие результатов и очистка. Проверено отсутствие дополнительных экранов и подключение Medium с весом 500. Визуальное совпадение в настоящем браузере нужно проверить отдельно.
