# Прототип Figma: поиск по "Моя карта"

Исходный SVG-экспорт страницы сохранён как `frame-33.svg`. Это визуальный макет, а не интерактивный прототип. 
[Figma](https://www.figma.com/design/MUmNLy3AH9uvYo8XbH43YD/3-курс?node-id=0-1&p=f&t=XIsOL5iotE82q90y-0)

## Задача пользователя

Найти нужный проект, навык или запись об образовании в "Моя карта", чтобы использовать её в резюме или портфолио.

## Состояния для прототипа

1. **Моя карта — все записи.** Пустое поле «Поиск» и четыре карточки из исходного макета.
2. **Моя карта — результаты.** В поле введено `Figma`, видна только карточка «Дизайн образовательной платформы», показан счётчик «Найдено: 1» и крестик очистки.
3. **Моя карта — нет совпадений.** В поле введено `аналитика`, вместо карточек — «Ничего не найдено».

## Переходы

- Нажатие на поле в первом состоянии переводит к подготовленному состоянию с результатом.
- Из состояния с результатом можно перейти к примеру без совпадений через отдельное действие редактирования запроса.
- Крестик и кнопка «Показать всю карту» возвращают к первому состоянию.
